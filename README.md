# 📊 Sales Analytics Dashboard – Excel

## Project Overview

An interactive Sales Analytics Dashboard created using Microsoft Excel.

This project focuses on cleaning raw sales data, analyzing sales performance, and presenting insights through an interactive dashboard.

## Data Cleaning

- Identified and handled missing values
- Removed duplicate records
- Standardized text values
- Corrected date and number formats
- Prepared data for analysis

## Dashboard KPIs

- **Total Revenue:** 1,264,761.96
- **Total Orders:** 1,200
- **Average Order Value:** 1,053.97
- **Customer Count:** 1,189

## Analysis

- Revenue by Product
- Payment Method Analysis
- Yearly Revenue Trend
- Order Status Distribution
- Customer Analysis

## Interactive Filters

- Product
- Payment Method
- Order Status
